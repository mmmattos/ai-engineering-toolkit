# Serverless Architecture

> Design production serverless systems around managed execution, event-driven workloads, and operational simplicity.

# Purpose

Evaluate serverless components according to workload characteristics rather than treating serverless as a default architecture.

Consider:

- stateless execution
- event triggers
- cold starts
- execution limits
- concurrency
- retries
- idempotency
- state and persistence
- observability
- security
- cost
- vendor coupling

Use managed services where they reduce operational burden without creating unacceptable architectural constraints.
