# Explain Go Code

Explain the Go code currently under consideration.

If the request refers to a symbol under the cursor:

- Identify the symbol and its kind.
- Explain its purpose and behavior.
- Explain its type or signature.
- Explain parameters and return values.
- Explain relevant interfaces, dependencies, and relationships.
- Use the surrounding code when necessary.

If code is selected:

- Explain what the selected code does.
- Walk through the important logic.
- Explain relevant Go language features and patterns.
- Point out important assumptions, side effects, or potential issues.

Focus on the requested code rather than explaining the entire file.

Use clear, concise language appropriate for an experienced Go developer.
